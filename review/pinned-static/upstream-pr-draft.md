# feat: pin static image translation results from Compact

感谢作者在 #769 中对交互和架构的指导。这一版按建议改为：先在 Compact 中完成截图、OCR 和翻译，再通过工具条上的 Pin 按钮把结果固定为独立的置顶贴图。

对应原反馈，改动如下：

1. 保留原有 Standalone / Compact 两种模式，不增加第三模式，也不新增快捷键配置。Pin 成功后关闭当前 Compact，原有入口可以继续处理下一次截图。
2. 贴图只持有静态显示结果。复用冻结的原图、标注图和矢量译文覆盖层，复制两层文字的选择数据；没有独立 ViewModel、OCR/翻译任务、自动重算、防抖、执行协调器或延迟服务释放。
3. 原文、译文均支持拖选、双击选词、三击选段和复制。段落归属复用现有分段分析结果，软换行不会截断整段；裁剪的译文仍保留完整复制文本。空白右键提供复制全文、原图/译文切换、阴影开关和关闭，空白区域可以拖动。
4. 多个贴图相互独立。后续服务、语言、分段和显示层设置变化不会改写已固定内容；菜单语言使用现有动态资源。新截图框选期间暂时隐藏贴图与阴影，完成或取消后恢复。
5. 保留前版的黑色阴影和激活蓝色辉光。独立 Chrome 窗口用于外扩效果和鼠标穿透；窗口内容仍复用 ImageZoom。新增贴图没有工具条，静态图不创建缩放动画。

与现有架构的关系：主窗口截图/翻译分发、服务管理、OCR 插件和快捷键配置保持上游实现；现有布局分析器只附带已经确定的原始段落归属，未改变分段规则。新增协调器只管理贴图集合和截图隐藏/恢复。旧预览版 pinned 配置迁移放在现有 Settings 文件中。

验证：Debug、Release 构建零警告、零错误；个人审阅分支的自动回归 315 项通过。窗口级检查覆盖多窗隐藏恢复、截图期间新建/关闭窗口及关闭后的回收。测试和完整说明保留在 [个人审阅分支](https://github.com/Lne27/STranslate/tree/feature/pinned-static-review/src/Tests/STranslate.Tests)，性能程序和原始结果见 [窗口测量](https://github.com/Lne27/STranslate/tree/feature/pinned-static-review/review/pinned-static)，不将审阅材料加入本 PR。

性能上，没有额外的空闲轮询或 OCR/翻译调用；固定样本的快照复制均值约 7.64 微秒、12 KB 托管分配。30 个静态窗口的 3 秒空闲采样未测到进程 CPU 时间增长，隐藏/恢复中位数约 33.4 ms。图片与原外观要求的 WPF/Chrome 表面仍占内存（该组私有内存增量约 161 MiB），不将窗口成本描述为零，也不把屏幕外微基准等同于真实桌面帧率。
